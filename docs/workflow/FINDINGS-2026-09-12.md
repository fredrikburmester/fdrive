## Limits

- Archive extraction is incremental: a conflict stops the job and preserves existing files, but earlier new outputs remain. No rollback is promised.
- `overwrite:false` is atomic where the provider supports conditional creation (WebDAV). SFTPGo cannot guarantee this against independent external writers, another identity or another API process; the local archive-job lock serializes jobs for the same identity/path within one process.
- Draft retention covers navigation inside the current tab. Drafts are not persisted across a closed/reloaded tab.
- Imported files without hashes need a normal indexing pass before derivative rebuilds can include them.
